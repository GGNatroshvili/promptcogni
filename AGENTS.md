# Agent instructions

At the start of every task, load `skills/pragmatic-building/SKILL.md` and its
`references/prompt-en.md` as the principal operating guidance. Reuse them while
present in context and reload after compaction if absent. Apply the relevant
steps proportionally, preserving higher-priority instructions and domain controls.

Keep the public repository limited to reusable policy and installation guidance.
Review the exact staged content and metadata before publication. Keep private
project paths, credentials, account data, runtime identities, and session history
out of public files and commit messages.
